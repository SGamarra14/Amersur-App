## 📝 Descripción
**Amersur-App** es una herramienta desarrollada como proyecto integrador que optimiza la interacción entre la inmobiliaria y el cliente. Permite explorar un catálogo dinámico de propiedades, gestionar usuarios y asegurar que la información multimedia esté siempre disponible mediante servicios en la nube.

## 🚀 Características Principales
* **Gestión de Catálogo:** Visualización interactiva de inmuebles con detalles técnicos y galerías multimedia actualizadas.
* **Sincronización Cloud:** Integración con **Firebase Realtime Database** para mantener los datos de venta y alquiler actualizados al instante.
* **Autenticación de Usuarios:** Sistema de registro e inicio de sesión seguro para clientes mediante **Firebase Auth**.
* **Almacenamiento en la Nube:** Uso de **Firebase Storage** para la gestión eficiente de imágenes de alta resolución sin comprometer el rendimiento del dispositivo.
* **Filtros Inteligentes:** Implementación de búsqueda personalizada para localizar propiedades según criterios específicos.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Java (Android Nativo).
* **Backend:** Firebase (Database, Storage & Auth).
* **Diseño:** Android XML con enfoque en experiencia de usuario (UX).
